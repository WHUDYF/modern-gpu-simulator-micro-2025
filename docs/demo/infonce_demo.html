InfoNCE 的具体思想

解释对比学习 loss 如何利用同 graph 的两个 view 做正样本，用 batch 内其他 graph 做负样本。
positive pair negative pairs temperature=0.2 cross entropy
1. InfoNCE 在拉近什么
正样本

同一个 graph 的 view A 和 view B 是正样本对。

负样本

batch 里其他 graph 的 view 是负样本。

目标

正样本相似度要高，负样本相似度相对低。

InfoNCE 训练的是 projection output；projection head 之后的 64D 不进入 selector。

InfoNCE 伪代码
{
  "normalize": "L2 normalize projections",
  "logits": "a @ b.T / temperature",
  "labels": "diagonal index",
  "loss": "CE(logits, labels) + CE(logits.T, labels)"
}
关键参数
fieldvalue
temperature0.2
projection_output64D
optimizerAdam(lr=0.005)
一句话公式
a = normalize(proj(view_a)) b = normalize(proj(view_b)) logits = a @ b.T / T labels = arange(batch_size) loss = (CE(logits, labels)+CE(logits.T, labels))/2
