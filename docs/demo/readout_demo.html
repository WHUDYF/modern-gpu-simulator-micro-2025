Readout 的具体实现

解释 node embedding 如何分层聚合成 kernel embedding，为什么不能直接把所有节点平均。
node→warp warp→CTA CTA→SM kernel=selected SM
1. Readout 为什么分层
Node 到 warp

每个 warp partition 内，对所有节点 embedding 做 mean pooling。

Warp 到 CTA

同一个 CTA 下的 warp embedding 再 average。

Selected SM 到 kernel

selected SM 的 embedding 直接作为 kernel embedding。

这个层级保留了 warp partition 和 CTA 边界，比直接全图平均更接近 GCL 的结构假设。

一句话公式
warp = mean(node_embeddings in partition) cta = average(warp embeddings) selected_sm = average(cta embeddings) kernel_embedding = selected_sm
