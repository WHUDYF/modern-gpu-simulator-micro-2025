3 层 RGCN 的具体结构

解释当前 GCL encoder 如何按 relation type 做 message passing，以及 64 维 node feature 如何变成 256 维 node embedding。
input 64D hidden 128D output 256D relation_count=3
1. RGCN 一层内部做什么
自身信息

self_linear 处理当前节点自己的特征，避免节点只依赖邻居。

关系消息

control_flow、data_source、data_destination 三种边各有独立 relation_linear。

聚合更新

源节点经过对应关系矩阵变换后，加到目标节点表示上，再做 LayerNorm 和 ReLU。

注意：3 层 RGCN 输出的是 node embedding，还不是 kernel embedding。kernel 级表示要经过 readout。

关键参数
fieldvalue
dropout前两层 0.1，最后一层 0
normalizationLayerNorm
activationReLU
一句话公式
for each relation r: messages = W_r(h_source) h_target += aggregate(messages) h_next = ReLU(LayerNorm(h_target))
