双视角训练过程

解释为什么同一个 graph 要生成两个 view，以及 node dropping、edge dropping、feature noise 在训练中起什么作用。
view A view B node_drop=0.15 edge_drop=0.15 noise=0.01
1. 两种视角怎么生成
View A / View B

同一个 canonical graph 用不同 seed 生成两个扰动图。

扰动内容

随机丢非 instruction 节点、随机丢边，并给 feature 加小噪声。

训练目标

两个 view 来自同一个 graph，所以它们的表示应该靠近。

augmentation 只用于训练；正式导出 selector embedding 时必须回到 canonical non-augmented graph。
