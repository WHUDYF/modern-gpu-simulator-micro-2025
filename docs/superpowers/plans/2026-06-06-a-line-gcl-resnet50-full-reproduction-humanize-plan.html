GCL ResNet-50 Humanize Implementation Plan

这是从 full reproduction draft 生成的 humanize plan 总览：包含 Gate0-9 的验收标准、正负测试、路径边界、依赖顺序和实施提示。

20 AC 每条验收标准都有 positive / negative tests。
Gate0-7 最低 formal scope：真实 trace 到 correctness evaluation。
Gate8-9 作为我们的扩展：tuning vector 和 simulator evaluation。
Report Only Gate7 第一版指标只量化，不强制阈值。

Milestone Sequence

M1

Formal Boundary

修正 Gate1-5，使 fixture 只能 debug，不能 formal pass。

M2

Real Trace

Gate0 采集真实 ResNet-50 NVBit trace 和 scheduler metadata。

M3-4

Graph + Embedding

Gate1-5 从 trace 生成 graph tensor 和 256D kernel embedding。

M5-6

Selector + Eval

Gate6 聚类选 representative，Gate7 定量验证分组可信度。

M7

Extension

Gate8-9 进入 tuning proposal 和 sampled-vs-full simulator evaluation。

Plan Relationship

Key Boundaries

Formal Path
  • 真实 ResNet-50 NVBit trace 是必要输入。
  • Gate6 clustering 只能使用 256D canonical embeddings。
  • Gate7 不修改 Gate6 assignment。
Rejected Path
  • fixture / synthetic trace 不得 formal pass。
  • projection head output 不得作为 selector embedding。
  • 没有 full baseline 不得声明 speedup。
Gate7 的 quantitative metrics 是必须记录、可复现、可比较的证据；第一版不把它们写成 enforced thresholds。
