GCL ResNet-50 Gate 1-5 总体实施计划

本轮从真实完整 ResNet-50 NVBit trace adapter 开始，到 Gate 5 输出 canonical 256 维 kernel embedding table 为止。Gate 6 的 clustering、family classification 和调参策略留到下一轮。synthetic / ResNet-like fixture 只能用于测试，不能作为 formal 输入。

起点 真实完整 ResNet-50 NVBit trace artifacts，必须带真实 SM/CTA metadata。
核心 representative SM -> canonical graph -> tensor -> RGCN training。
终点 kernel_embedding_table.json，256 维 canonical embedding。
非目标 本轮不做 cluster、family 分类、调参比例预测。

Gate 1-5 数据流

每个 Gate 都只消费上一个 Gate 的正式 artifact。正式 artifact 必须继承真实 ResNet-50 provenance；fixture、synthetic trace 或 hand-written opcode 只能进入 debug / test path。

Gate 1

Trace Adapter

解析真实完整 ResNet-50 NVBit trace，输出 formal resnet50_trace_adapter_bundle.json。

Gate 2

Representative SM

运行 scheduler_signature_medoid_sm，输出 representative-SM manifest。

Gate 3

Canonical Graph

按 warp 建图，再合并为 kernel canonical graph bundle。

Gate 4

Tensorization

生成 node_features、edge_index、edge_type。

Gate 5

RGCN Embedding

训练 RGCN，使用 canonical graph 导出 256 维 kernel embedding。

实现任务

Task 1: 构造小规模 ResNet-like Gate 1 test fixture，但必须标记为 debug / test，不能 formal pass。
Task 2: 实现 Gate 1 adapter bundle。
Task 3: 从 adapter bundle 生成 Gate 2 representative-SM manifest。
Task 4: 给 Gate 3/4 artifact 补齐 representation mode。
Task 5: 把 Gate 5 readout 改为 node -> warp -> CTA -> selected SM -> kernel。
Task 6: 新增 Gate 1-5 pipeline，并停止在 embedding table。
Task 7: 增加 replay / hash deterministic 检查。
Task 8: 跑 focused tests、Phase A/B regression 和 CLI smoke。
