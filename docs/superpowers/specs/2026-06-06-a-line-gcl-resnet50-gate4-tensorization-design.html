Gate 4: Tensorization

Gate 4 把 Gate 3 的 canonical graph bundle 转换为 GNN/RGCN 可消费的 tensor bundle，并严格复用 GCL-Sampler Phase A 的 64 维 node feature schema。

输入 canonical_graph_bundle.json，来自 Gate 3。
Node Feature node_features.shape = [node_count, 64]。
Typed Edges edge_index + edge_type 保留 relation type。
下一步 Gate 5 才做 augmentation、RGCN training 和 embedding export。

1. Gate 4 流程

Gate 4 只负责把 graph artifact 变成 tensor artifact，不改变 canonical graph。

Canonical Graph

  • nodes
  • edges
  • warp partitions
  • graph hash

Stable Index

  • node_id -> index
  • preserve graph node order
  • edge source / target index

Node Features

  • [node_count, 64]
  • instruction / variable / pseudo layout
  • strict zero padding

Edge Tensors

  • edge_index [2, E]
  • edge_type [E]
  • relation schema preserved

Gate 5 Input

  • graph tensor bundle
  • warp partition tensors
  • graph batch metadata

2. Tensor Bundle

Gate 4 输出 graph_tensor_bundle.json，每个 graph 对应一个 tensor artifact。

{
  "artifact_type": "gcl_resnet50_graph_tensor_bundle",
  "artifact_version": "gate4_graph_tensor_bundle_v1",
  "source_canonical_graph_bundle_hash": "...",
  "tensors": [],
  "graph_tensor_bundle_hash": "..."
}
Gate 5 只读取 tensor bundle，不再读取 Gate 3 graph bundle 或原始 trace。

3. 64 维 Node Feature Layout

Gate 4 严格复用 gcl_m2_phase_a_paper_node_feature_v1。不同 node type 使用不同 block，但总宽度固定为 64。

Instruction Node
[0:63) opcode_token_embedding
[63]
Variable Node
[0:32) variable_token_embedding
[32:40) dynamic stats
[40:64) zero padding
Pseudo Node
[0:16) pseudo_token_embedding
[16:64) zero padding
Gate 4 strict path 不把 control bits、predicate、active mask、cache hint 或其他扩展字段加入 64 维 feature。后续若要加入，必须作为单独 ablation。

4. Edge Tensor 示例

Gate 3 的 typed graph edges 会转换为 edge_index 和 edge_type。

Graph Edge node index edge_type
I0 -> I1 edge_index[:,0] = [0, 1] control_flow = 0
V0 -> I0 edge_index[:,1] = [4, 0] data_source = 1
I0 -> V1 edge_index[:,2] = [0, 5] data_destination = 2 
edge_index.shape = [2, edge_count]
edge_type.shape  = [edge_count]

5. Warp Partition Tensors

Warp partitions 从 graph node IDs 转换为 tensor node indices，供后续 node -> warp -> kernel readout 使用。

Graph Partition 
partition_id = "1:0"
node_ids = ["I0", "I1", "V0", "V1"]
edge_ids = ["e0", "e1"]
Tensor Partition 
partition_id = "1:0"
node_indices = [0, 1, 4, 5]
edge_indices = [0, 1]
instruction_count = 2

6. 通过标准

  • node_features.shape = [node_count, 64]。
  • edge_index.shape = [2, edge_count]。
  • edge_type.shape = [edge_count]。
  • feature schema 必须是 gcl_m2_phase_a_paper_node_feature_v1。
  • variable node 的 [40:64) 必须 zero padding。
  • pseudo node 的 [16:64) 必须 zero padding。
  • warp partition tensor 的 node / edge index 全部有效。
  • tensor_hash 和 graph_tensor_bundle_hash 可复现。
  • tensorization 不修改 canonical graph artifact。
