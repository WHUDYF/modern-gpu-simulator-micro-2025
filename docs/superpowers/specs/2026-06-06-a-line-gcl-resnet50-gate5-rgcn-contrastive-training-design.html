GCL ResNet-50 Gate 5：RGCN Contrastive Training

Gate 5 消费 Gate 4 的 graph tensor bundle，训练 RGCN encoder，并只用 canonical non-augmented graph 导出 256 维 kernel embedding。它不做 clustering，也不做 family classification。

输入 graph_tensor_bundle.json，来自 Gate 4。
训练 augmentation + 三层 RGCN + projection head + InfoNCE。
导出 canonical graph inference，输出 256 维 kernel embedding。
下一步 Gate 6 使用 embedding table 做 cluster / family classification。

Gate 5 Pipeline

Gate 5 的核心边界是：augmentation 只服务训练，正式 embedding 必须来自未增强的 canonical tensor。

1. Tensor Bundle

node_features、edge_index、edge_type、warp_partition_tensors。

2. Training Views

同一个 graph 生成两个 augmented views，形成 positive pair。

3. RGCN Training

Relation-specific message passing，输出 node embeddings。

4. Canonical Export

关闭 augmentation / dropout，导出 256 维 kernel embedding。

5. Gate 6

只读取 kernel_embedding_table.json。

Gate 5 验收重点

输入 tensor hash 可复现，shape 与 Gate 4 schema 一致。
Augmentation 不覆盖 canonical tensor。
Positive pair 来自同一个 kernel invocation。
RGCN 输出 node embeddings 为 256 维。
Readout 使用 node -> warp -> CTA -> selected SM -> kernel。
Projection head 只用于 InfoNCE loss。
正式导出使用 canonical non-augmented tensor。
kernel_embedding_table.json 输出 256 维 embedding。
