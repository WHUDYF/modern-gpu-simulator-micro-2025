GCL ResNet-50 Gate 6 Selector / Family Evidence

Gate 6 消费真实完整 ResNet-50 Gate 5 formal kernel_embedding_table.json， 在 256 维 canonical kernel embedding 上执行 silhouette-K、deterministic K-Means、representative anchor 选择， 并在 clustering 之后评估 cluster-to-family evidence。

输入 只接受真实 ResNet-50 Gate5 formal 256 维 canonical embedding。
默认 K 使用 silhouette_k，让 embedding space 自己选择 cluster count。
输出 cluster assignments、representative anchors、family evidence report。
非目标 不做 supervised head、调参比例预测、speedup 或 accuracy claim。

Gate 6 数据流

Gate 6 的 clustering 只能使用 256 维 embedding。kernel name、family label、runtime、graph size 等字段只能在 clustering 完成后用于 evidence report。

Input

Gate5 Embedding

读取真实 ResNet-50 formal kernel_embedding_table.json，拒绝 fixture / projection head / augmented view。

Normalize

Z-Score

对 256 维 embedding 做 z-score；零方差维度置 0 并记录。

K Select

Silhouette-K

尝试候选 K，选择 silhouette score 最高的 K；并列时选更小 K。

Cluster

K-Means

在 normalized embedding 上运行 deterministic K-Means，不读取 forbidden fields。

Anchor

Representative

每个 cluster 选择距离 centroid 最近的真实 kernel invocation。

Evidence

Family Report

聚类完成后再读取 family evidence，计算 purity 和 mixed-family clusters。

Formal Input 必须满足

workload_id = resnet50
model = torchvision.models.resnet50
execution_mode = real_trace
trace_source = nvbit
scheduler_metadata_source = real_nvbit_smid
input_scope = full_resnet50_inference_trace
embedding_source = canonical_non_augmented_graph
embedding_dim = 256
projection_head_used_for_selector = false
任何 synthetic、ResNet-like fixture、hand-written opcode、mini-transformer、simulator replay、projection head output 或 augmented-view embedding 都不能进入 Gate 6 formal path。

禁止参与聚类的字段

No Labels

语义标签不能偷看

  • kernel_name
  • family_label
  • operator_name
  • layer_name
No Runtime

运行时信息不能参与距离

  • runtime_ms
  • weight_input
  • trace_order
  • source_path
No Graph Stats

图规模不能决定 cluster

  • opcode_histogram
  • node_count
  • edge_count
  • graph_size_class

输出 Artifact

embedding_validation_report.json 验证 row count、256 维 embedding、hash、真实 ResNet-50 provenance 和 forbidden debug 输入。
embedding_normalization_report.json 记录 z-score normalization、mean/std hash、zero variance dimensions 和 normalized embedding hash。
k_selection_report.json 记录 silhouette-K 候选、score、selected K 和 tie-break 结果。
kmeans_cluster_assignment_table.json 记录 deterministic K-Means assignments、centroid hash、assignment hash 和 convergence metadata。
representative_anchor_table.json 每个 cluster 选择一个最近 centroid 的真实 kernel invocation，并记录 member coverage。
cluster_family_evidence_report.json 聚类之后计算 family distribution、purity、mixed-family clusters 和 no-family-claim 状态。

验收重点

必须成立
  • 只接受真实 ResNet-50 Gate5 formal embedding。
  • clustering 只使用 256 维 canonical embedding。
  • 默认 silhouette-K，K-Means assignment 可复现。
  • representative 必须是真实 input row。
必须隔离
  • family label 只能用于 post-clustering evidence。
  • mixed-family cluster 必须报告，不能静默成功。
  • Gate6 不输出调参比例，不声明 speedup。
  • Gate7 才讨论 supervised head 或调参策略。
