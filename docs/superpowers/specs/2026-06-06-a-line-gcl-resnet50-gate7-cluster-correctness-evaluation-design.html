GCL ResNet-50 Gate 7 Cluster Correctness Evaluation

Gate 7 不重新聚类、不训练 head、不预测调参。它消费 Gate 6 selector artifacts， 用 embedding geometry、family alignment、representative quality、metric consistency 和 run stability 定量评估 GCL 分组是否可信。

输入 真实 ResNet-50 Gate6 formal selector artifacts。
5 层 几何、family、representative、metric、stability。
report only 第一版只量化，不伪装成已证明正确。
Gate 8 前置 调参策略必须先读取 Gate7 evidence。

Gate 7 五层定量验证

Gate7 的核心是把“cluster 已生成”拆成多层证据。每层都输出独立 report，并在 manifest 中记录 source hash。

Layer 1

Embedding Geometry

silhouette、Davies-Bouldin、Calinski-Harabasz、intra/inter distance。

Layer 2

Family Alignment

purity、weighted purity、ARI、NMI、homogeneity、completeness、V-measure。

Layer 3

Representative

mean / p95 distance to representative、centroid rank、outlier ratio。

Layer 4

Metric Error

runtime、SM cycles、memory throughput、simulator time 的 weighted MAPE 和 p95 error。

Layer 5

Stability

多 seed / 多 split 的 assignment ARI、K stability、centroid drift、anchor stability。

关键定量指标

Geometry
  • silhouette_score
  • davies_bouldin_index
  • calinski_harabasz_index
  • inter_intra_distance_ratio
Family
  • cluster_purity
  • weighted_cluster_purity
  • adjusted_rand_index
  • normalized_mutual_information
Anchor
  • p95_distance_to_representative
  • representative_rank_to_centroid
  • outlier_member_ratio
  • high_weight_outlier_count
Metric
  • cluster_weighted_mape
  • cluster_p95_relative_error
  • global_weighted_mape
  • high_weight_bad_cluster_count
Stability
  • assignment_stability_ari
  • k_stability
  • centroid_drift
  • representative_stability_rate
Policy
  • threshold_policy = report_only_v1
  • claim_status = quantified_no_correctness_claim
  • threshold_claim_status = not_set_until_real_resnet50_baseline

输出 Artifact

cluster_embedding_quality_report.json 记录 silhouette、DBI、CH、cluster radius、separation、inter/intra ratio。
cluster_family_alignment_report.json 记录 purity、weighted purity、ARI、NMI、homogeneity、completeness、mixed clusters。
representative_quality_report.json 记录 representative 到 members 的距离分布、outliers 和 coverage weight。
cluster_metric_error_report.json 记录 representative 对 members 的 measured / simulator metric relative error。
cluster_stability_report.json 记录多 run assignment ARI、K stability、centroid drift 和 representative stability。
gate7_cluster_correctness_manifest.json 汇总 source hashes、report hashes、threshold policy 和 claim status。

第一版边界

可以声明
  • GCL cluster 已被多层指标量化。
  • family label 只用于 post-clustering evaluation。
  • representative 质量和 metric error 可审计。
  • 缺失数据会被显式标记。
不能声明
  • GCL 分组已经被最终证明正确。
  • sampled simulation speedup 已成立。
  • 调参策略已经可靠。
  • single-run 结果已经稳定。
Gate7 第一版使用 threshold_policy = report_only_v1。等真实 ResNet-50 baseline 数据足够后，才能升级到 enforced threshold。
