# 基于图对比学习的GPU仿真加速技术

基于图对比学习的GPU仿真加速技术

丁逸夫 吴弘煜 付嘉琪

摘  要：本文围绕GPU kernel结构相似性分析，系统介绍了图神经网络（GNN）与K-means聚类的基本原理，并在此基础上复现了GCL方法，通过这两种方法来减少GPU模拟器需要模拟的kernel数量，从而加快模拟器的整体模拟时间，提高GPU的架构搜索效率。首先，将GPU执行轨迹中的kernel构造成异构关系图，利用R-GCN对图结构进行编码，学习kernel的嵌入表示；随后在嵌入空间中采用K-means对kernel进行无监督聚类，并选取代表kernel进行分析。实验以ResNet50执行轨迹为对象，共获得265个kernel样本，最终聚类结果为K=2，其中一个簇包含263个样本，另 一个簇包含2个样本。结果表明，GCL能够在无监督条件下捕捉kernel之间的结构相似性，并识别少量结构差异明显的kernel，但其聚类结果仍需结合后续解释模块和硬件计数器进一步验证。

关键词： GNN，K-means，GCL，GPU kernel，图对比学习，聚类

GPU kernel 是 GPU 程序执行和性能分析的基本单元。一个深度学习模型或科学计算程序在运行过程中通常会产生大量 kernel 调用，不同 kernel 在指令组成、访存模式、控制流结构和数据依赖关系上存在差异。这些差异直接影响程序在 GPU 上的执行效率，也决定了后续性能建模、代表样本选择和模拟器分析的复杂度。因此，如何从大量 kernel 调用中提取结构特征、发现相似 kernel，并选取具有代表性的样本，是 GPU 工作负载分析中的重要问题。

传统 kernel 分析方法通常依赖人工设计的统计特征，例如指令数量、访存比例、线程块规模、执行时间或硬件性能计数器等。这类方法具有较好的可解释性，但难以完整表达 kernel 内部复杂的依赖关系和图结构信息。对于深度学习模型产生的大量 kernel，仅依靠手工特征进行分组，可能忽略指令之间的数据依赖、控制依赖以及访存关系等结构差异。

为了解决这一问题，本文将 GPU kernel 执行轨迹表示为图结构，并引入图神经网络（Graph Neural Network，GNN）对其进行编码[1]。GNN能够通过消息传递机制聚合邻居节点信息，将 kernel 中的指令节点、依赖边和访存关系共同映射到低维嵌入空间。进一步地，本文采用图对比学习（Graph Contrastive Learning，GCL）在无标签条件下训练图编码器，使结构相似的 kernel 在嵌入空间中更加接近，结构差异较大的 kernel 相互区分。

在获得 kernel 嵌入向量后，本文使用 K-means 算法进行无监督聚类。K-means 根据样本在嵌入空间中的距离关系，将 kernel 划分为若干簇，并从每个簇中选择距离聚类中心最近的样本作为代表 kernel。按照功能划分，GNN和GCL主要承担 kernel 结构表示学习任务，K-means则承担聚类分析和代表样本选择任务。二者结合后，可以形成一条从 GPU 执行轨迹到 kernel 结构分组的完整分析流程。

因此，本文首先介绍 GNN 的基本原理，其次介绍 K-means 聚类算法，然后在二者基础上说明 GCL 方法的复现过程，并通过 ResNet50 kernel 执行轨迹实验分析该方法在 kernel 结构相似性学习中的效果。

## 1 图神经网络相关知识

## 1.1 图神经网络的基本概念

图是一种通用的数据结构，能够有效地建模实体（节点）及其之间的关系（边）。现实世界中的大量数据本质上是图结构，例如社交网络（用户与好友关系）、化学分子（原子与化学键）、交通网络（路口与路段）等。传统深度学习模型（如卷积神经网络、循环神经网络）主要处理欧几里得数据（如规则网格的图像、时序序列），无法直接应用于图结构数据——因为图的节点连接无序、大小可变，且不具备平移不变性。

图神经网络（Graph Neural Network，GNN）正是为解决这一问题而提出的。其核心思想是：通过迭代地聚合邻居节点的特征信息，学习每个节点的向量表示（嵌入），从而将图的结构和节点特征整合到深度学习框架中。

## 1.2.3 主要挑战：过平滑问题

随着GNN层数的加深，重复聚合会导致不同节点的嵌入逐渐趋同，最终趋向于同一个向量，这种现象称为过平滑。它使得深层GNN难以学到有区分度的节点表示，是训练深层模型的主要障碍。

常用的缓解策略包括引入跳跃连接（残差连接）、采用图门控机制、训练浅层（通常2～4层）但表达能力更强的模型（如GAT）等。

## 1.3 典型应用场景

GNN已在多个领域展现出显著效果：

社交网络：用户推荐、社区检测、影响力分析；

化学与药物发现：分子属性预测、化学反应预测；

知识图谱：链接预测、关系推理；

计算机视觉：场景图生成、点云分类；

交通预测：路况预测、智能调度。

## 1.4 本章小结

本章系统介绍了图神经网络的基本原理与训练方法。GNN通过消息传递机制将图拓扑结构与节点特征统一到深度学习中，解决了传统神经网络无法直接处理非欧几里得数据的难题。其训练过程基于半监督学习范式，使用交叉熵损失和反向传播算法可有效地从部分标记的图数据中学习。然而，过平滑问题仍是限制GNN表达能力的瓶颈。未来，动态图处理、大规模图学习以及图变换器等方向将是研究的重点。

K-means也存在一定局限性。该算法需要预先确定聚类数，对初始聚类中心较为敏感，并主要适用于簇形状近似为球形、不同簇尺度相近的数据。对于非球形分布、簇密度差异较大或包含明显离群点的数据，K-means可能难以获得稳定的聚类结果。

## 3 基于GNN与K-means的代表kernel选择方法

前文已经分别介绍了图神经网络和K-means聚类算法的基本原理。本章在此基础上，进一步说明本文如何将二者结合起来，完成基于图对比学习（Graph Contrastive Learning，GCL）的GPU kernel结构相似性分析实验。整体而言，GNN负责从GPU kernel图中学习结构表示，GCL负责在无标签条件下训练图编码器，K-means负责在嵌入空间中完成聚类和代表kernel选择。

## 3.1 实验方法总体框架

本实验参考GCL-Sampler中“轨迹构图-图编码-对比学习-聚类采样”的基本流程，将GPU kernel执行轨迹转化为图结构数据，并利用图神经网络学习kernel的嵌入表示。与传统依赖手工特征的kernel聚类方法不同，该流程能够利用kernel内部的指令关系、数据依赖、控制依赖和访存结构，从而获得更丰富的结构表示。

## 3.2 Kernel执行轨迹的图结构表示

GPU程序运行时会产生大量kernel invocation。每个kernel内部包含指令序列、寄存器依赖、访存操作、控制流跳转等信息。如果只使用指令数量或访存比例等统计量，会丢失大量结构信息。因此，本实验首先将每个kernel invocation构造成图。

对于第i个kernel invocation，其图结构可表示为：

G_i = (V_i, E_i, X_i, R_i)

其中，V_i表示节点集合，E_i表示边集合，X_i表示节点特征矩阵，R_i表示关系类型集合。节点可以表示指令或基本块，节点特征包含指令类型、访存类型、操作数相关信息等；边表示不同节点之间的结构关系，例如：

指令顺序边

数据依赖边

控制依赖边

访存相关边

这种图结构能够比普通向量特征更完整地表达kernel内部执行模式。对于GPU kernel而言，不同类型的边具有不同含义，因此本文采用异构关系图表示kernel执行轨迹，而不是将所有边视为同一种连接。

## 3.3 基于R-GCN的Kernel图编码

由于kernel图中包含多种边关系，普通GCN难以区分不同关系的语义。因此，本实验使用关系图卷积网络（Relational Graph Convolutional Network，R-GCN）作为图编码器。R-GCN的特点是对不同关系类型使用不同的权重矩阵，从而在消息传递过程中保留边类型信息。

对于节点v在第l层的表示，R-GCN的更新过程可写为：

hv(l+1)=σ( ∑r ∈ R ∑u ∈ Nr(v) 1/cv,r Wr(l) hu(l)+ W0(l) hv(l))

其中，R表示关系类型集合，Nr(v)表示通过关系r连接到节点v的邻居节点集合，Wr(l)表示第l层中关系r对应的可训练参数，W0(l)表示节点自身特征的变换参数，cv,r为归一化系数，σ表示非线性激活函数。

经过多层R-GCN传播后，每个节点的表示都融合了其邻域结构信息。随后，通过图读出函数将节点表示汇聚为整个kernel图的表示：

zi = READOUT({hv(L) | v in Vi})

其中，zi为第i个kernel invocation的图级嵌入向量。本实验中，每个kernel最终被编码为256维向量。该向量既包含节点特征信息，也包含由边关系传递得到的结构信息。

仅使用R-GCN编码器还不足以完成无监督学习，因为实验数据中并没有人工标注的kernel类别。因此，本文引入图对比学习作为训练目标，使模型能够在无标签条件下学习kernel之间的结构相似性。

## 3.5 基于K-means的Kernel嵌入聚类

完成GCL训练后，每个kernel invocation都被表示为一个固定维度的嵌入向量。设全部kernel嵌入向量为：

Z = {z1, z2, ..., zn}, ziin ℝ256

此时，原始的图结构分析问题转化为向量空间中的无监督聚类问题。本文使用K-means对这些嵌入向量进行聚类，其优化目标为：

J = sumk=1Ksumziin Ck||zi- μk||22

其中，Ck表示第k个簇，μk表示对应聚类中心。K-means通过不断执行样本分配和中心更新，使簇内样本距离尽可能小。

为了降低人工指定K值带来的主观性，本文使用轮廓系数评价不同K值下的聚类效果。对于样本i，轮廓系数定义为：

s(i) = (b(i)-a(i)) / max{a(i), b(i)}

其中，a(i)表示样本i与同簇内其他样本之间的平均距离，b(i)表示样本i与最近其他簇之间的平均距离。平均轮廓系数越高，说明簇内越紧密、簇间越分离。

## 3.6 代表Kernel选择方法

聚类完成后，需要从每个簇中选择一个具有代表性的kernel，用于后续分析。本文采用距离聚类中心最近的样本作为代表kernel。对于第k个簇，其代表kernel编号为：

ik*= arg mini: ziin Ck||zi- μk||2

该样本位于簇中心附近，能够在一定程度上代表同簇kernel的平均结构特征。通过这种方式，可以从大量kernel invocation中筛选出少量代表样本，降低后续人工分析或模拟验证的成本。

需要注意的是，代表kernel只表示其在嵌入空间中接近簇中心，并不意味着它一定具有明确的硬件机制语义。若要进一步解释某个簇对应的机制类型，还需要结合kernel名称、图规模、指令统计、访存特征和硬件性能计数器进行验证。

聚类结果为：

从结果可以看出，大部分kernel被划分到cluster 0，只有少量kernel被划分到cluster 1。这说明当前GCL嵌入空间能够将少数结构差异明显的kernel从主体样本中分离出来。但由于两个簇的规模差异较大，该结果更适合解释为“主体样本与少量特殊样本的分离”，而不应直接解释为两个明确的功能类别或硬件机制类别。

## 4.8 实验结果分析

cluster 0包含263个样本，说明ResNet50中大多数kernel invocation在当前图嵌入空间中较为接近。这可能是因为同一神经网络模型中的kernel在调用模式、图规模或指令结构上具有一定相似性。

cluster 1只包含2个样本，说明这两个kernel在结构表示上明显偏离主体样本。造成这种现象的原因可能包括：

图规模明显不同

指令组成比例不同

访存行为差异较大

## 4.9 本章小结

本章说明了本文如何结合GNN和K-means完成GCL复现实验。首先，将GPU kernel执行轨迹构造成异构关系图；其次，使用R-GCN对kernel图进行编码；然后，通过图对比学习在无标签条件下训练图编码器；最后，在学习到的256维kernel嵌入空间中使用K-means完成聚类和代表kernel选择。

实验结果表明，该方法能够从ResNet50的265个kernel invocation中识别出主体kernel群组和少量结构特殊kernel。整体来看，GNN提供了图结构编码能力，GCL提供了无监督表示学习目标，K-means提供了聚类与代表样本选择方法。三者结合后，可以形成一条完整的GPU kernel结构相似性分析流程。

## 4    结语与展望

本文基于图对比学习（GCL）构建了一套GPU kernel结构相似性学习与代表样本压缩方法。该方法首先将GPU kernel执行轨迹表示为图结构，再通过R-GCN学习kernel嵌入表示，最后利用K-means完成聚类与代表kernel选择。实验结果表明，该方法能够在保留主要结构信息的前提下，将约255个kernel invocation压缩为2个代表性模拟对象。

这一结果说明，GCL不仅能够有效识别kernel之间的结构相似性，还能够显著减少后续模拟与分析所需的对象数量，从而降低模拟开销、提升GPU模拟效率。相比逐个kernel进行全量仿真，该方法更适合用于架构探索阶段的快速筛选与迭代验证，能够为GPU架构参数调优和设计空间探索提供更高效的前端支撑。
